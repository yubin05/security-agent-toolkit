## 찾아보고 알게 된 것
- .venv는 프로젝트 폴더마다 따로 쓰는 파이썬 환경. 여기에 설치한 패키지는 다른 폴더에 영향을 주지 않는다
- GitHub에는 빈 폴더를 만들 수 없어서, 폴더 안에 파일을 하나 만들면 폴더가 같이 생긴다

## 막힌 것
- 코랩에서 되던 코드가 VS Code에서 `SyntaxError: f-string: unmatched '['`
  - 원인: f-string 안에서 바깥과 같은 큰따옴표를 겹쳐 쓰는 건 Python 3.12부터 가능. PC의 파이썬 버전이 더 낮았음
  - 해결: 안쪽을 작은따옴표로 → `f"{data['message']}"`
- VS Code에서 `normalized_logs.json`을 열면 `FileNotFoundError`
  - 원인: 코랩에서는 드라이브의 agent_core 폴더 안에서 실행했지만, VS Code는 지금 열린 PC 폴더를 기준으로 파일을 찾음
  - 해결: 파일을 PC의 security-agent-toolkit/agent_core로 옮기고 그 폴더를 열어서 실행
