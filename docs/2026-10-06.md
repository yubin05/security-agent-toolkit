## 찾아보고 알게 된 것
API 키는 클라우드 LLM 서비스에 "이 요청은 허가된 사용자가 보냈다"고 증명하는 비밀번호 같은 값이다. 호출량(토큰)만큼 요금이 붙기 때문에 키가 유출되면 남이 내 비용으로 LLM을 쓰는 피해(LLMjacking)가 난다. 그래서 코드가 아니라 .env 에 두고 .gitignore 로 막는다.
LLM은 글(프롬프트)을 입력받아 글(응답)을 내놓는 프로그램이다.
무료 등급은 공짜인 대신 분당 요청 수(RPM)·일일 요청 수(RPD)·분당 토큰 수(TPM)에 제한이 걸린다. 넘으면 429(RESOURCE_EXHAUSTED)가 나오고, 키 고장이 아니라 기다리면 풀린다. 한도는 모델·시기에 따라 바뀐다.
보안 담당자가 다루는 서버는 대부분 리눅스다. 서버 OS 점유율 자료에서 리눅스가 약 63%로 가장 많았다(자료마다 수치가 다름).
깃배시를 쓰면 윈도우에서도 서버와 같은 bash 명령(ls, grep, curl, 파이프)을 그대로 연습할 수 있다. PowerShell은 출력을 객체로, bash는 텍스트로 다룬다는 차이가 있다.

## 키가 틀렸을 때와 키가 없을 때의 차이
- 틀린 키: UNAUTHENTICATED (키는 보냈는데 값이 틀림)
- 키 없음: PERMISSION_DENIED (신원 정보를 아예 안 보냄)
