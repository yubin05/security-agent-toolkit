# 1과목 회고 (yubin05)

## 내가 만든 것
- 경보를 LLM으로 판단하고 보고서를 만든 뒤 알림까지 보내는 파이프라인(pipeline.py, notifier.py)을 만들었다. `run_pipeline` 한 줄이면 처음부터 끝까지 이어서 돌고, 기준이나 알림 주소는 config.json만 바꿔서 조절한다.

## 가장 어려웠던 것
- 에러 없이 틀린 결과가 나오는 논리 에러였다. high 경보가 4건인데 0건으로 나왔는데, 디버그 줄로 실제 값을 찍어 보고서야 대소문자와 공백 때문이라는 걸 알았다.

## 리뷰에서 찾은 것과 고친 것
- 체크리스트 리뷰에서 설정(모델 이름 하드코딩), 실패(timeout 없음), 기록(except: pass로 실패를 숨김) 세 곳을 어기고 있었다. 설정은 config로 빼고, 실패는 [알림 실패]를 출력하게 고쳤다.
- 테스트 파일(test_agent_core.py)을 만들어 고칠 때마다 한 번에 확인할 수 있게 했다.

## 캡스톤에서 더 해 보고 싶은 것
- 고객사마다 config만 바꿔 쓰는 구조를 유지하면서, 알림 실패 시 다시 보내는 재시도와 로그 파일 기록을 붙여 보고 싶다.
