## 찾아보고 알게 된 것
저장소와 내 폴더는 git 으로 연결된 짝이다. 깃허브 저장소가 원격(remote)이고, 내 PC 폴더가 로컬 저장소다. 내 PC 에서는 원격 저장소를 `origin` 이라는 짧은 이름으로 부른다.

git 을 쓰는 이유는 파일을 웹에서 하나씩 올리지 않고, 바뀐 기록(버전)을 한꺼번에 남기고 되돌릴 수 있기 때문이다.
