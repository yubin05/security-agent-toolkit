## 찾아보고 알게 된 것
add는 다음 기록에 넣을 변경을 고르는 단계다. commit은 고른 변경을 내 PC의 저장소에 기록하고, push는 로컬 커밋을 GitHub 같은 원격 저장소로 보낸다. 세 단계를 나누면 여러 변경 중 필요한 것만 묶어 기록할 수 있다.

commit 메시지는 무엇을 왜 바꿨는지 알려 주는 설명이다. 문서 변경에는 docs:를 사용한다. push는 작업 폴더의 모든 파일을 올리는 명령이 아니라 커밋된 기록을 보내는 명령이다.

untracked는 아직 Git이 추적하지 않는 새 파일이고, tracked는 이미 Git이 추적하는 파일이다. tracked 파일을 수정해도 다시 add하기 전까지 수정 내용은 다음 커밋에 들어가지 않는다. staged는 다음 커밋에 넣기로 선택한 변경이며, tracked와 별개의 상호 배타적인 파일 종류는 아니다.

add한 뒤 파일을 다시 고치면 staged 내용과 작업 폴더 내용이 달라질 수 있다. 최신 수정도 기록하려면 다시 add해야 한다. 잘못 고른 변경은 git restore --staged 파일명으로 선택만 취소할 수 있다.

.gitignore는 주로 추적하지 않는 파일을 제외하는 규칙이다. 이미 추적 중인 파일에는 규칙을 추가해도 추적이 자동으로 해제되지 않는다.
