# 2026-10-13 (화)

## 오늘 새로 쓴 명령
cat, grep

## 오늘 쓴 옵션
- `-n` : 찾은 줄에 줄 번호를 붙인다
- `-c` : 조건에 맞는 줄 수를 숫자로 보여 준다

## 찾아보고 알게 된 것
grep은 파일에서 검색 조건에 맞는 줄을 골라 보여 주는 명령이다. 보안 담당자는 긴 서버 로그에서 로그인 실패나 오류 기록을 빠르게 찾아 조사 범위를 좁히는 데 사용한다. 검색 결과는 확인할 단서이며, 실패 기록이 있다는 사실만으로 공격을 확정하지 않는다.

cat은 파일 내용을 전체 출력한다. 짧은 로그는 cat으로 먼저 확인하고, 긴 로그에서는 grep으로 필요한 기록을 골라 읽을 수 있다.

`-n`은 원본 파일에서 몇 번째 줄인지 알려 주고, `-c`는 검색에 일치한 줄의 개수만 출력한다. `-c`는 단어의 등장 횟수가 아니다. 같은 줄에 ‘실패’가 두 번 있어도 한 줄로 센다.

## 내 실습 파일과 확인 결과

파일: `network_zt/sample.log`. 실제 서버에서 수집한 로그가 아니라 수업에서 제공한 여섯 줄의 연습 데이터이다.

```text
09:00 로그인 성공
09:03 로그인 실패
09:10 와이파이 연결
09:12 와이파이 끊김
09:20 로그인 실패
09:25 인터넷 연결
```

| 명령 | 확인한 결과 | 의미 |
|---|---|---|
| `cat sample.log` | 위 여섯 줄 | 파일 전체 확인 |
| `grep "실패" sample.log` | `09:03 로그인 실패`, `09:20 로그인 실패` | 검색 조건에 맞는 두 줄 |
| `grep -n "끊김" sample.log` | `4:09:12 와이파이 끊김` | 원본 파일의 4번째 줄 |
| `grep -c "실패" sample.log` | `2` | 일치한 줄의 개수 |

2026-10-13 문서화 과정에서 Git for Windows에 포함된 cat·grep으로 기존 파일을 직접 읽어 위 결과를 확인했다. 실습 데이터와 명령 결과를 구분하며, 실제 로그인 실패 사고를 측정한 결과로 표현하지 않는다.

## 막힌 것

문서의 ‘grep은’ 설명이 비어 있어 보완했다. 기존 sample.log는 여섯 줄이 맞았고, 검색·줄 번호·개수 결과도 과제의 예상 결과와 일치했다.
