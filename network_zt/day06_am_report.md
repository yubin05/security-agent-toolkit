## 4교시 · PDP 와 PEP · ZT 성숙도 점수 · A사 적용 방안 문서

### 문제 4-1 · 직원 정보로 ZT 성숙도 점수 계산하기

- (가) 내가 바꾼 코드 네 줄을 붙여 넣어 주세요.
  - 쓸 내용: `# ←` 네 곳에 바꾼 코드(점수 계산식 세 줄 · 총점 한 줄)
  - 답: 아래 네 줄이며, 앞에서 `staff_count = len(STAFF)`로 직원 수를 구한다. Python 3에서는 `/`가 실수를 반환하므로 `float` 변환은 생략해도 된다.

```python

mfa_score = (float)(mfa_count/staff_count) * 20                                                # MFA 적용률 점수. 0 을 계산식으로 바꾼다 (1줄)   # ←
device_score = (float)(device_count/staff_count) * 20                                             # 기기 보안 점검 비율 점수. 0 을 계산식으로 바꾼다 (1줄)   # ←
least_score = (float)(least_count/staff_count) * 20                                              # 최소권한 준수율 점수. 0 을 계산식으로 바꾼다 (1줄)   # ←

total = mfa_score + device_score + least_score + seg_score + risk_score                                                    # 총점. 0 을 다섯 점수의 합으로 바꾼다 (1줄)   # ←
```
