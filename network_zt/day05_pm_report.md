  - 쓸 내용: 「X: 평균 … ms · 지터 … ms / Y: 평균 … ms · 지터 … ms / Z: 손실 … %」

- (나) 🔍 평균 지연만 보면 Y 가 더 좋아 보입니다. 화상회의에는 어느 회선이 더 나쁠까요? 왜 그런가요?

## 6교시 · 코드로 계산과 판정

### 문제 6-1 · 지터 함수 직접 만들기

- (가) 직접 만든 `jitter` 함수를 독스트링과 함께 아래 코드 블록에 붙여 넣어 주세요.
  - 쓸 내용: 독스트링을 쓴 함수를 복사해 아래 코드 블록에 붙여 넣기
  - 답:

```python
def jitter(got):                          # 받은 값 리스트 got 으로 지터를 구해 리턴하는 함수이다. 이 함수를 직접 만든다
    """받은 응답 시간 목록으로 이 실습의 지터를 계산한다.

    입력: 응답 시간(ms) 목록 got. 값이 두 개 이상이어야 한다.
    반환: 이웃한 응답 시간 차이의 절댓값 평균(ms).
    """
    # 1. total 을 0 으로 시작한다
    total = 0
    # 2. for 와 range(1, len(got)) 로 위치 i 를 꺼내, i 번째 값과 바로 앞 값의 차이의 절댓값을 total 에 더한다
    for i in range(1, len(got)):
        total += abs(got[i]-got[i-1])
    # 3. total 을 (got 의 개수 - 1) 로 나눈 값을 리턴한다
    return total / (len(got)-1)
```

- (나) 함수를 채운 뒤 실행해 나온 세 줄을 그대로 옮겨 적어 주세요.
  - 쓸 내용: 터미널 출력 세 줄을 복사해 붙여 넣기
  - 답:
```text
회선 A | 지연 21.9 ms | 지터 1.1 ms | 손실 0 %
회선 B | 지연 42.3 ms | 지터 54.3 ms | 손실 0 %
회선 C | 지연 41.0 ms | 지터 1.7 ms | 손실 30 %
```

- (다) `jitter` 함수의 리턴값은 무엇이고, `measure` 의 어느 줄에서 어떻게 쓰이나요?
  - 쓸 내용: ① 리턴하는 값이 무엇인지 ② 그 값을 받는 줄(`measure` 안)
  - 답: 지터(ms)는 수신 응답의 인접 절대차 평균이다. `jitter_value = jitter(got)`에서 받아 `round(jitter_value, 1)`로 출력하며, None 제외 후 값 2개 이상이 전제이고 C는 손실 30%도 함께 판단한다.

### 문제 6-2 · 세 회선을 화상회의 기준으로 판정하기

- (가) 세 회선의 판정 결과(적합 · 부적합)와 걸린 기준을 각각 적어 주세요.
  - 쓸 내용: 「A: … / B: … (걸린 기준 …) / C: … (걸린 기준 …)」
  - 답: A: 적합(지연 21.9ms·지터 1.1ms·손실 0%). B: 지터 54.3ms>30ms로 부적합 / C: 손실 30%>1%로 부적합이며, 지연 기준은 150ms 이하이다.
- (나) 회선 C 는 지연과 지터가 작은데도 왜 부적합인가요? 어제(10/15) 오후 문제 5-2 에서 본 것과 연결해 적어 주세요.
  - 쓸 내용: ① C 의 손실률과 기준 ② 손실이 통신에 주는 영향 한 가지
  - 답: C는 지연 41ms·지터 1.7ms는 기준 이하지만 손실 30%가 기준 1%를 넘는다. TCP 재전송처럼 지연이 늘거나 실시간 음성·영상이 끊길 수 있으며, 모든 화상회의 데이터가 재전송되는 것은 아니다.
- (다) 🔍 `ok` 를 `and` 로 이은 이유는 무엇인가요? `or` 로 이으면 회선 B 의 판정이 어떻게 달라지나요?
  - 쓸 내용: ① `and` 로 이은 이유 ② `or` 로 이으면 B 의 판정이 어떻게 달라지는지
  - 답: and는 세 기준을 모두 만족해야 True이다. or면 B도 지연 42.3ms≤150ms를 만족해, 지터 초과에도 적합으로 오판한다.
- (한 줄) 고객에게 보낼 답을 한 문장으로 적어 주세요.
  - 쓸 내용: 고객이 바로 읽을 수 있는 한 문장(어느 회선이 되고 안 되는지, 이유 한 가지)
  - 답: 제시된 기준에서 A는 적합하고, B는 지터 54.3ms>30ms, C는 손실 30%>1%로 부적합합니다.
- 이 교시에서 새로 알게 된 것 하나를 적어 주세요.
  - 쓸 내용: 자유롭게
  - 답: 지터 함수는 응답 시간의 인접 절대차를 평균하고, 품질 판정은 지연·지터·손실을 and로 묶어야 한다는 것을 배웠다. C처럼 지터가 낮아도 손실 기준을 넘으면 부적합이라는 점이 기억에 남는다.
