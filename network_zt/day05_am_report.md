## 4교시 · 구역 규칙 코드

### 문제 4-1 · 규칙 판정 코드 읽고 설명하기

- (가) 함수 `default_policy` · `match_rule` · `judge` 가 각각 무엇을 하는지 적어 주세요.
  - 쓸 내용: 「default_policy: … / match_rule: … / judge: …」 함수마다 자유롭게
  - 답: default_policy: 규칙 불일치 시 같은 구역·inside 출발·outside 도착은 허용하고 나머지는 차단한다. match_rule: 출발·도착·포트 일치를 True/False로 반환한다. judge: 요청 하나에 첫 일치 규칙을 적용하고 없으면 기본 정책을 적용한다.
- (나) `judge` 가 리턴하는 값 두 개는 무엇이고, 어느 줄이 만드나요?
  - 쓸 내용: 「값 ①: … / 값 ②: … / 만드는 줄: …」
  - 답: 반환값은 동작(permit/deny)과 규칙 번호이다. 일치 시 `return rule[4], rule[0]`, 불일치 시 `return default_policy(src, dst), 0`이며, 0은 기본 정책 표시로 허용도 가능하다.
- (다) 🔍 `judge` 의 `for` 는 맞는 규칙을 찾으면 바로 `return` 합니다. 같은 요청에 규칙이 둘 이상 맞는다면 어느 규칙이 적용되나요? 왜 `return` 으로 바로 끝내도록 만들었나요?
  - 쓸 내용: ① 규칙이 둘 이상 맞을 때 적용되는 규칙 ② 방화벽이 「첫 번째로 맞는 규칙」을 쓴다는 점과 이어서 `return` 으로 바로 끝내는 이유
  - 답: 위에서 처음 맞은 규칙을 적용한다. `return`이 함수 전체를 끝내므로 아래 규칙이 결과를 덮지 않는다.

### 문제 4-2 · 허용 포트 목록 함수 채우고 흐름 그리기

- (가) 채운 `allowed_ports` 함수를 붙여 넣고, 실행해서 나온 출력 네 줄을 적어 주세요.
  - 쓸 내용: ① 채운 함수 ② 출력 네 줄
  - 답: 작성 함수와 출력 네 줄은 아래와 같으며, 실제 실행 결과가 요구사항의 기대 목록과 일치했다.

```python
def allowed_ports(src, dst, ports):
    result = []
    for port in ports:
        action, no = judge(src, dst, port)
        if action == "permit":
            result.append(port)
    return result
```

```text
[443]
[445]
[22, 80, 443, 445, 3389]
[]
```

출력은 순서대로 outside → DMZ, DMZ → inside, inside → DMZ, outside → inside에서 허용된 시험 포트 목록이다. 세 번째 목록은 내부망에서 출발하는 통신을 허용하는 기본 정책의 결과이고, 마지막 빈 목록은 시험한 포트 중 허용된 것이 없다는 뜻이다.

- (나) `judge` 함수의 흐름을 ASCII 도식(상자 · 화살표)으로 그려 아래 코드 블록에 넣어 주세요.
  - 쓸 내용: 코드 블록 안에 ASCII 도식을 직접 그리기(상자 안은 영어 · 숫자)
  - 답: 첫 일치 규칙에서 반환하고, 끝까지 없으면 기본 정책을 반환하는 흐름이다.

```text
START: src, dst, port
  |
  v
[ Any rules left? ] -- no --> RETURN (default_policy(src,dst), 0)
  |
  | yes
  v
[ Take next rule ]
  |
  v
[ match_rule ? ] -- no --> back to [ Any rules left? ]
  |
  | yes
  v
RETURN (rule[4], rule[0])
        action, rule number
```

- (다) 🔍 `allowed_ports` 에서 `result = []` 를 `for` 위에 두는 이유는 무엇인가요? `for` 안에 두면 어떻게 되나요?
  - 쓸 내용: ① `result = []` 를 `for` 위에 두는 이유 ② `for` 안에 두면 달라지는 점
  - 답: for 밖에서 리스트를 만들어야 허용 포트가 누적된다. 안에 두면 매번 비워져 마지막 3389가 허용될 때만 [3389], 아니면 []이며, return도 for 밖에 둔다.
- (한 줄) 고객에게 보낼 답을 한 문장으로 적어 주세요.
  - 쓸 내용: 고객이 바로 읽을 수 있는 한 문장(요구사항이 지켜졌는지)
  - 답: 시험 포트 22·80·443·445·3389에서 인터넷→DMZ는 443만, DMZ→내부망은 445만, 내부망→DMZ는 모두 허용되고 인터넷→내부망은 모두 차단되어 기대 목록과 일치했습니다.
- 이 교시에서 새로 알게 된 것 하나를 적어 주세요.
  - 쓸 내용: 자유롭게
  - 답: 첫 일치에서 return하고, 규칙 0은 차단이 아닌 기본 정책이라는 점을 배웠다. 리스트는 반복문 밖에서 초기화해야 누적되며, 시험 포트의 코드 검증이 실제 장비 전체 검증은 아니라는 점이 기억에 남는다.
